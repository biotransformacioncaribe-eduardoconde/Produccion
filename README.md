# Biotransformación SAS — Control de Producción V1.185

Aplicación web de control de producción de Biotransformación SAS.

## Publicación en GitHub Pages

1. Cree un repositorio en GitHub.
2. Suba `index.html` a la raíz del repositorio.
3. En **Settings → Pages**, seleccione **Deploy from a branch**.
4. Seleccione la rama principal (`main`) y la carpeta `/ (root)`.
5. Guarde y espere la publicación de GitHub Pages.

## Importante

- Esta versión utiliza almacenamiento local del navegador (IndexedDB) para sus datos operativos.
- Los datos guardados en un dispositivo/navegador no se sincronizan automáticamente con otros dispositivos.
- La aplicación utiliza componentes externos para generación de PDF; el dispositivo necesita acceso a Internet para cargarlos cuando sean requeridos.
- La versión oficial aprobada es **V1.185**.
